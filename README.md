# 낱말 블록

블록을 쌓아 가로·세로로 한글 낱말을 완성하는 놀이입니다.
1~5단계는 글자(음절) 블록으로, 6단계부터는 자음과 모음이 따로 떨어지는 자모 블록으로 진행합니다.

---

## 실행하기

의존성 없이도 그대로 돌아가고, Vite로 빌드할 수도 있습니다. 어느 쪽이든 같은 소스를 씁니다.

### 1. 빌드 없이 바로 보기

브라우저가 ES 모듈을 그대로 읽으므로 정적 서버만 있으면 됩니다.

```bash
npx serve nadmal-blocks
```

파일을 두 번 눌러서 여는 방식(`file://`)은 모듈 보안 정책 때문에 동작하지 않으니 반드시 서버로 여셔야 합니다.

### 2. 개발 서버

```bash
npm install
npm run dev
```

### 3. 배포본 만들기

```bash
npm run build     # dist/ 에 생성됩니다
npm run preview   # 만들어진 결과를 확인합니다
```

### 4. 시험

```bash
npm test
```

한글 자모 처리, 레벨 설계, 낱말 판정을 34개 항목으로 확인합니다. 브라우저 없이 돌아갑니다.

---

## 배포

Vercel은 `vercel.json`을 보고 그대로 처리합니다.

```bash
vercel --prod
```

빌드 없이 정적 파일만 올리셔도 됩니다. 그때는 `index.html`이 있는 폴더를 그대로 올리시면 됩니다.

하위 경로에 올리실 계획이라면 `vite.config.js`의 `base`를 그 경로로 바꿔 주세요.

## 놀이 규칙

### 읽는 방향

가로는 **왼쪽에서 오른쪽**으로, 세로는 **위에서 아래**로 읽습니다.
화면에 보이는 그대로 읽어서 맞아야 하므로, 세로로 「나무」를 만들려면 「무」를 먼저 떨어뜨리고 그 위에 「나」를 얹어야 합니다.

### 단계별 진행

| 구간 | 블록 | 음절 수 | 낙하 속도 | 레벨당 낱말 | 목표 자모 공급 |
| --- | --- | --- | --- | --- | --- |
| 1~5 | 글자 | 2 → 3 | 1100 → 740ms | 5개 | 2개 연속 + 방해 0~1 |
| 6~10 | 자모 | 2 → 2·3 | 900 → 620ms | 10개 | 3개 → 2~3개 연속 |
| 11~15 | 자모 | 3 | 550 → 320ms | 15개 | 2~3개 → 2개 연속 |
| 16 이상 | 자모 + 겹받침 | 2·3 | 300ms부터 레벨마다 12ms씩 빨라짐 (하한 140ms) | 17개 | 2개 연속 + 방해 1~2 |

5단계를 마치면 계속할지 묻습니다. 아니오를 고르면 거기까지의 점수로 정산하고 마칩니다.
점수는 구간과 상관없이 하나로 쌓이고, 랭킹도 한 표입니다.

### 인정 기준

* **글자 블록** — 순서를 그대로 맞춰야 합니다. 목표가 아니어도 사전에 있는 낱말이면 보너스로 인정합니다.
* **자모 블록** — 자모 개수가 같고, 순서대로 조합해 목표와 같거나 자모 구성이 같으면 인정합니다. 상하좌우로 이어져 있으면 꺾인 모양도 인정합니다.

### 점수

```
글자 수 × 100 × (목표 낱말이면 2배) × 레벨 × 연쇄 배수
```

연쇄 배수는 이어서 지울 때마다 0.5씩 늘어납니다.

### 보조 수단

* **별 5개** — 하나를 쓰면 블록 한 칸을 지웁니다. 목표 낱말을 맞히면 하나 돌아옵니다.
* **HOLD** — 블록 하나를 보관합니다. 한 턴에 한 번만 쓸 수 있습니다.
* **정지** — 판마다 3회까지 쓸 수 있습니다.
* **자동 힌트** — 블록이 일정 수만큼 쌓이면 글자마다 첫소리를 차례로 알려 주고, 끝내 못 맞히면 정답을 보여 준 뒤 다음 낱말로 넘어갑니다.

## 고치고 싶을 때

| 하고 싶은 일 | 고칠 곳 |
| --- | --- |
| 난이도, 속도, 레벨당 낱말 수 | `src/config/levels.js` |
| 낱말과 뜻풀이 추가 | `src/config/words.js` |
| 판 크기 | `src/core/board.js`의 `COLS`, `ROWS` |
| 색 | `src/styles/tokens.css` |
| 온보딩 장면 | `src/ui/onboarding.js`의 `DEMOS` |
| 랭킹을 서버에 저장 | `src/services/ranking.js`의 `loadScores`, `saveScore` |

낱말을 추가하실 때는 **2음절 또는 3음절**만 넣어 주세요. 판 너비가 10칸이라 자모 9개까지 들어가는데, 4음절이 되면 가로로 늘어놓을 수 없습니다. `npm test`가 이 조건을 확인합니다.

## 개발용 점검 창구

개발 서버로 열거나 주소에 `?debug=1`을 붙이면 콘솔에서 `window.__nb`를 쓸 수 있습니다.

```js
__nb.info()                        // 지금 상태를 한눈에
__nb.goLevel(16)                   // 특정 레벨로 건너뛰기
__nb.setTarget('무지개')            // 목표 낱말 바꾸기
__nb.clearBoard()                  // 판 비우기
__nb.put(11, 2, ['나', '무'])       // 원하는 자리에 놓아 보기
__nb.check()                       // 지금 판에서 완성된 낱말 찾기
```

실제 배포본에서는 열리지 않습니다.

## 알아 두실 점

**랭킹은 지금 브라우저에만 저장됩니다.** 기기 사이에 공유되지 않습니다. 서버로 옮기실 때는 `src/services/ranking.js`의 두 함수만 바꾸면 화면 코드는 그대로 두셔도 됩니다.

**점수를 브라우저가 계산해서 그대로 보냅니다.** 순위 경쟁을 진지하게 다루실 계획이라면 서버에서 점수를 다시 확인하는 절차를 함께 두셔야 합니다.

**한 판이 꽤 깁니다.** 16단계에 닿으려면 낱말 150개를 맞혀야 합니다. 짧게 만들고 싶으시면 `src/config/levels.js`의 `goalOf`를 낮추시면 됩니다.
